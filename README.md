# skill-memory — 通用踩坑沉淀技能

让 AI agent 记住踩过的坑，第二次直接走通，不再重复试错。


> 以下内容需要放到AGENTS.md中，触发"要沉淀"这个念头的是 AGENTS.md；让 agent 找到"用 skill-memory 来做"的是 description；
```text
# 全局 Agent 工作准则（每次会话自动加载）

> 本文由 DSH 硬加载（`~/.dsh/AGENTS.md`）。**只放稳定不变的元规则（纪律）**；沉淀协议、三层模板、质量门槛等具体方法见 `skill-memory`，避免本文档膨胀。

## 核心原则：试错只付一次

1. **第一次执行允许试错**：陌生流程/站点/格式可以探测、反复调整。
2. **第二次执行不得重复试错**：同一流程再执行时，先复用已沉淀经验，命中即走通。
3. 实现手段：每次踩坑、被纠正、找到「黄金路径」后，**必须沉淀**为持久记忆。

## 何时必须沉淀（触发条件，出现任一即使用`skill-memory`技能）

- 反复试错才解决（改了 ≥2 次才成功）
- 用户纠正做法 / 表达不满 / 指出错误
- 发现可复用「黄金路径」（第一次就做对、值得固化）
- 遇到登录 / 反爬 / 结构变化等非显然的坑

## 每次执行任务前 / 后

- **执行前**：若这是以前做过的流程（skill 或纯任务），先查该流程的历史经验，**若命中已知坑/已知做法，先按经验走，不要从头试错**。
- **执行后**：对照触发条件，有则按 `skill-memory` 协议沉淀（具体步骤与落点见 skill-memory）。

## 沉淀方法的自我更新

- 发现更好的记忆/沉淀方式时，更新 `skill-memory`（方法层），让所有 skill 受益。
```


## 它解决什么问题

让 AI 第一次做某件事时，它可能反复试错、来回折腾才弄对；可过几天再做同样的事，它又从头试错一遍，完全不记得上次怎么解决的。

`skill-memory` 就是解决这个问题的：**第一次允许踩坑，但把教训沉淀下来，第二次直接复用，不再重复踩坑。**

## 它有什么好处

- **效率翻倍**：同一流程第二次执行时，agent 会先「命中历史经验」再动手，而不是从零摸索。
- **一套方法适用所有技能**：网页抓取、写代码、做文档、跑流程……任何 skill 都能用它沉淀经验，不局限于某个领域。
- **自我成长**：沉淀方法本身也在进化——发现更好的记忆方式时更新自己，让所有技能受益。
- **防记忆膨胀**：内置质量门槛与去重，只沉淀「具体、可复用、不重复、已脱敏」的经验，不会被垃圾信息撑爆。

## 它如何工作

`skill-memory` 把经验按「谁来读」分成三层：

| 层 | 读者 | 存什么 | 例子 |
|---|---|---|---|
| 机器层 | 代码自动加载 | 确定性配置 | 网页抓取的「选这个容器、开有头模式」 |
| 经验层 | agent 主动读 | 代码表达不了的教训 | 「这个站有反爬，必须开有头模式」 |
| 流程层 | agent 主动读 | 流程本身怎么跑 | 「先探测结构，再写抓取配置」 |

**闭环流程**：踩坑 → 按层沉淀 → 第二次执行时 agent 先读记忆、报告「命中了哪几条」→ 命中即走通。

## 如何使用

### 自动生效（无需手动操作）

它与全局纪律文件 `~/.dsh/AGENTS.md` 配合，**每次会话自动生效**：

- `~/.dsh/AGENTS.md`：全局元规则，每次启动自动加载，提醒 agent「试错只付一次、踩坑必须沉淀」。
- `skill-memory`：具体协议与模板，agent 需要沉淀时调用它。

### 什么时候会触发

agent 在任意任务中遇到以下任一情况，就会自动沉淀：

1. 反复试错才解决（改了 2 次以上）
2. 你纠正了它的做法，或表达了不满
3. 它发现了一条可复用的「黄金路径」
4. 遇到登录、反爬、结构变化等非显然的坑

### 你可以怎么用

- **正常使用其他技能**（如 `web-analysis-ai` 抓数据）：踩坑后 agent 会自动沉淀，无需你操心。
- **主动沉淀**：说「把这次的经验记下来」即可。
- **查看沉淀**：问「这个技能沉淀了哪些经验」，agent 会读给你看。
- **调整规则**：说「修改沉淀规则」，agent 会更新 `skill-memory` 和全局 AGENTS.md。

## 它借鉴了什么

这套方法不是凭空设计，综合了业界成熟方案：

- [Cline Memory Bank](https://docs.cline.bot/best-practices/memory-bank)：每次任务「先读记忆、结束更新记忆」的闭环协议
- [self-learning-claude](https://github.com/reshadat/self-learning-claude)：从失败中学习、跨会话持久化
- [claude-evolve](https://github.com/jack60810/claude-evolve)：给规则打分、优胜劣汰防腐化
- [Kulaxyz/self-learning-skills](https://github.com/Kulaxyz/self-learning-skills)：把「黄金路径」固化成可复用件

并补上了它们都缺的「读者分层 + 质量门槛 + 脱敏边界」。
